# Source code and rebuilding / 소스 코드와 다시 빌드하기

Each Paper Organizer release publishes its Windows installers and matching source files together on the same regular [GitHub release page](https://github.com/loselessss/paper-organizer/releases/latest).

Paper Organizer의 각 정식 [GitHub 릴리스](https://github.com/loselessss/paper-organizer/releases/latest)는 Windows 설치 파일과 대응 소스를 같은 Assets에 함께 제공합니다.

Download these files with the installer:

- `PaperOrganizer_Source_<version>.zip`
- `PaperOrganizer_Source_<version>.zip.sha256`
- `PaperOrganizer_Dependency_Sources_<version>.md`

The source ZIP contains the tagged Paper Organizer source and the complete pinned sPDF submodule source. The dependency document records exact source revisions, the build environment package versions, source locations, and rebuild commands. GitHub's automatically generated source archives do not include submodule contents, so use the attached ZIP when matching an installer.

소스 ZIP에는 해당 버전의 Paper Organizer 소스와 고정된 sPDF 서브모듈 소스 전체가 들어 있습니다. 의존성 문서에는 정확한 소스 리비전, 빌드 환경 패키지 버전, 소스 위치와 재빌드 명령을 기록합니다. GitHub가 자동 생성하는 소스 압축 파일에는 서브모듈 내용이 없으므로 설치 파일과 대응할 때는 Assets의 ZIP을 사용하세요.
